## 2026-05-31 - Fix failing tests by addressing Streamlit tabs and cursor mocking
**Learning:** In Streamlit test automation with `AppTest`, checking for tab rendering by looking at `at.tabs` fails when tabs have been refactored into segmented controls via `st.segmented_control`. Test tests need to mock the new UI state and explicitly set the correct active tab value in `st.session_state` and call `at.run()` to ensure the target tab content is rendered. Additionally, when testing DuckDB storage classes that rely on a custom singleton connection wrapper with `fetchall_as_pandas`, a simple mock connection class may be missing necessary DB-API cursor abstractions like a context-manager cursor. We must provide a full mock cursor that supports these methods.
**Action:** When updating tests for UI refactoring from tabs to segmented controls, explicitly drive the application state using `at.session_state` and `at.run()`. For testing custom connection wrappers in DuckDB, implement comprehensive mock objects that support full DB-API interactions such as `cursor()` and `fetchall_as_pandas()`.
