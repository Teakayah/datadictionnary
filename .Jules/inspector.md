## 2024-05-27 - Test Flakiness with os.environ Patching
**Learning:** Patching `os.environ` via `patch.dict` after a module has evaluated module-level configuration variables (e.g. `ENABLE_SEMANTIC_SEARCH = os.getenv(...)`) does not alter those variables. Additionally, globally patching `os.getenv` with a single return value is a highly dangerous anti-pattern that breaks other unrelated environment lookups.
**Action:** When a constant derived from an environment variable is imported at the module level, always patch it directly in the module namespace (e.g. `@patch("src.semantic.DATABRICKS_EMBEDDING_ENDPOINT", "my-endpoint")`). When the code calls `os.getenv()` dynamically, stick to the safe standard of `patch.dict(os.environ, {"VAR": "value"})` rather than mocking the `getenv` function itself.
