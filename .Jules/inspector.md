## 2026-05-03 - [Design System Test Assertions] **Learning:** Design system tests verifying string formatting (like § prefixes or sentence case) must assert against the `locale/en.json` i18n file rather than parsing the Python source code, as UI strings are no longer hardcoded in the templates. **Action:** When fixing or updating tests that check string formatting, verify where the strings are actually stored in the architecture and update test readers accordingly (e.g., using a `_read_locale_strings()` helper).
