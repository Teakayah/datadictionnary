## 2026-06-08 - Decoupling Streamlit tabs from Localized Labels
**Learning:** In Streamlit applications, coupling `st.segmented_control` (or tabs) state directly to localized text strings (e.g., storing the translated French label in session state) creates severe tech debt. It breaks UI state when the user switches languages, leading to convoluted workaround code (like index-based remapping tracking arrays of labels). Additionally, Streamlit's `AppTest` suite sometimes inconsistently passes lists to the `format_func` for single-select controls, requiring defensive handling in the lambda.
**Action:** Always decouple internal tab identifiers (e.g., "notable", "recent") from their UI representation. Pass a list of stable string IDs to the control and use the `format_func` property to resolve the localization dynamically at render time. Ensure the `format_func` defensively handles both `str` and `list` arguments.
