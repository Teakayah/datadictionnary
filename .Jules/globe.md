## 2026-05-02 - [Localization AppTest Assertions] **Learning:** When localizing UI elements (like `st.button`) in Streamlit, ensure `AppTest` assertions checking for specific element labels are updated to check against a tuple of supported localized strings (e.g., `b.label in ("Sign in", "Se connecter")`) so tests do not fail under different active locales. **Action:** Always review unit tests utilizing the `AppTest` framework that assert string presence after modifying UI elements' text to use `t()`, and update assertions using string tuples or the `t()` function directly.
