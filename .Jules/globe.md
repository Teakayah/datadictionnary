## 2025-05-04 - [Localization extraction] **Learning:** When localizing text strings embedded in Streamlit UI properties like `help` text, test files verifying app UI contents (like `test_app.py`) may be broken if they parse source code files looking for exact English text strings. Instead, rewrite those tests to load string values from the translation JSON files directly (using `json.load()` and `json.dumps(..., ensure_ascii=False)`) to verify translations. **Action:** Apply localized strings dynamically where applicable to pass `AppTest` or manual testing scripts without regex matches for hardcoded values.
