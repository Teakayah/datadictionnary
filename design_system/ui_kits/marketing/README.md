# Sign-in page — Data Dictionary (internal)

A **direct sign-in page** for the internal Data Dictionary tool. No hero, no selling, no demo CTAs — users land here and log in.

## Sections
1. `IntranetHeader` — logo + in-site nav only (Docs, Support). No external links.
2. `DirectSignIn` — the sign-in is the primary content. Left column identifies the tool in one paragraph; right column holds the Entra ID sign-in card with optional work-email input and SSO fallback.
3. `InternalFooter` — thin bar with Docs, `#data-platform` Slack, data-access policy.

Open `index.html` to see it.
