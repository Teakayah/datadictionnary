# Brand assets

| File | Use |
|---|---|
| `logo-wordmark.svg` | Full wordmark with mark. Marketing header, docs, emails. Min width 200px. |
| `logo-mark.svg` | Standalone filing-card mark. Favicon, app-rail, OG image corner. |
| `logo-mark-reverse.svg` | Mark on ink backgrounds. |

## Clear space
Reserve the width of the filing-card mark around the logo on all four sides.

## Don't
- Don't recolor the red dot — it is always `--accent` (`#B8362A`).
- Don't outline the card on colored backgrounds; use `logo-mark-reverse.svg` instead.
- Don't scale the wordmark below 180px width (the card detail disappears).
