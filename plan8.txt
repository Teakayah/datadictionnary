Does clicking an `<a>` tag with `target="_parent"` in an iframe trigger a hard reload of the parent page in Streamlit?
Streamlit intercepts clicks on `<a>` tags IF they are in the parent document and manage routing if using MPA. But since it's `target="_parent"`, the browser navigates the parent window to the new URL. This is a full page reload!
