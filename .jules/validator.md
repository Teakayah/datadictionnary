## 2026-08-01 - AppTest Component Mocking and ElementList Truthiness
Coverage Gap: Discovery page error states not properly testing the exception fallback logic
Learning: Streamlit's `AppTest.from_function()` creates an isolated execution context. If the original app function already defines mock patches internally (as is often done in tests to mock DB connections for the whole app), outer `patch` decorators in the test file will not override them. Furthermore, `ElementList` objects returned by `AppTest` evaluate incorrectly in logical `or` statements (`assert at.error or at.info`), creating tautological tests.
Assertion: Define a localized wrapper function inside the test that applies the patch before calling the component, and convert `ElementList` outputs to standard Python lists for reliable truthiness checks (e.g., `assert list(at.error) + list(at.info)`).
