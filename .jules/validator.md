## 2026-06-16 - Resolve i18n 'lang is not defined' Error
**Coverage Gap:** The `src/i18n.py` module had missing test coverage for the `lang` variable reference in `format_number` and `t` functions. A previous patch to refactor some code caused `lang` to be undefined when used.
**Learning:** Relying on implicit global scope or implicitly set session state values inside test execution can lead to unhandled exceptions when tests are run without a Streamlit execution context (e.g. `lang is not defined`). This frequently occurs if initializers/routing that typically populate `st.session_state` are not invoked within the test context.
**Assertion:** Added `lang = st.session_state.get('locale', 'en')` inside the relevant i18n functions. In Streamlit applications, always explicitly extract state within the function block using a safe accessor with a fallback (e.g. `.get()`) to prevent `NameError` in test suites.
