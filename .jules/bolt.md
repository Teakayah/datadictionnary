## 2024-05-01 - [Replaced iterrows with itertuples]
**Learning:** `iterrows()` is a major bottleneck when iterating over DataFrames in loops due to the overhead of boxing rows into `pd.Series` objects. Using `itertuples(index=False)` yields rows as lightweight namedtuples, providing a significant speedup (e.g., 10x-15x faster in benchmarks). However, since a namedtuple lacks a `.get()` method, attribute access must be updated to use `getattr(row, 'column_name', default)` to safely handle cases where the column might be missing, effectively mimicking the previous `.get()` fallback behavior.
**Action:** Always prefer vectorized operations in Pandas. If iteration over a DataFrame is strictly necessary (e.g., for complex conditional string building or integrating with non-vectorizable Streamlit UI components), always use `itertuples(index=False)` with `getattr` for safe attribute access, and avoid `iterrows()`.
