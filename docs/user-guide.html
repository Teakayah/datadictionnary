§ 1 — Overview

What is the Data Dictionary?

The Data Dictionary is an internal web application that gives everyone in the organisation a searchable, plain-English view of the data assets held in Databricks Unity Catalog. It shows you which tables exist, what they contain, who owns them, and who is allowed to access them — without requiring any technical knowledge of Databricks or SQL.

All results are automatically filtered to the tables you have permission to see. You will never encounter a table you cannot access, and you will never be asked to request access to something you already have.

Synced nightly. Catalog metadata (table names, descriptions, column types, grants) is refreshed every night from Unity Catalog. Changes you make via inline editing are applied immediately in the app and pushed to Databricks in the background.
§ 2 — Features

Full feature list

Features are grouped by the role required to use them.

All users Available to every authenticated user
Catalog search

Full-text search across table names, column names, descriptions, and business glossary terms. Results return in under 500 ms and include only tables you are authorised to access.

Table detail view

Per-table page showing catalog identifiers, description, steward, type, freshness, full column list with data types and business names, grant list, multi-hop lineage, downstream impact count, data quality grade, data sample, and CSV schema export.

Downstream impact

In the table detail sidebar: shows how many downstream assets depend on the selected table, with a warning when certified or production tables are in the blast radius.

Discovery tab

Four sub-tabs — Recommended (audit-log popularity, excludes already-viewed), New & Notable (recent edits in your group), My Bookmarks, and Recently Viewed.

Catalog browser

Hierarchical drill-down through catalogs → schemas → tables with permission filtering at each level.

Business glossary

Searchable list of business terms sourced from Unity Catalog metadata, with definitions, domains, stewards, and links to related tables.

Comments & questions

Leave a comment or flag on any table or column (max 1,000 chars) with one level of threaded replies. The table steward is notified by email when SMTP is configured.

Bookmarks

Star tables and columns to save them across sessions. Bookmarks are private to your account and persist when you sign out.

Recently viewed

Automatic chronological history of the last 50 tables you opened, updated on every visit to a detail page.

Health dashboard

Catalog-wide documentation coverage: percentage of tables and columns with descriptions, coverage by schema, and a priority-actions panel listing the five most under-documented tables.

Data quality badges

A–F grade badge on each discovery card and search result, sourced from Lakehouse Monitoring or Unity Catalog tags when available.

EN / FR interface

The full interface is available in English and French. Language is auto-detected and can be toggled per session with the EN / FR control in the header.

Power users Members of EDITOR_GROUPS
Inline metadata editing

Edit table descriptions, steward email, and column business names and definitions directly on the detail page. Changes appear instantly in the app.

Metadata proposals

Column overrides submitted by non-admin editors are queued as pending approval and must be reviewed by an admin before syncing to Databricks. Table-level edits (description, steward) are applied immediately.

Admins Members of ADMIN_GROUPS
Metadata approval queue

Review column override proposals submitted by editors. Approve to publish to Unity Catalog immediately; reject to discard. Every action is audit-logged.

Quality Insights tab

Three reports: high-impact gaps (popular tables missing descriptions or stewards), stewardship gaps (all tables without a steward), and DQ alerts (tables failing automated quality checks).

CMS announcements

Publish pinned cards above the Discovery feed — announcements, featured tables, and guides — with configurable expiry (2 / 7 / 30 days or never).

Pipeline management

Define, trigger, monitor, and cancel named pipeline runs. Three backends: Databricks Jobs, Azure Data Factory, Azure DevOps Pipelines. Live status polls every 3 seconds.

Sync queue dashboard

Inspect the pending-sync drain queue, daemon heartbeat, and DR resync status. Identify stalled rows and confirm successful propagation to Databricks.

Audit log

Full append-only log of all metadata edits, approvals, and rejections with actor email, timestamp, and before/after values.

Global editing toggle

Disable inline editing for all users without redeploying — useful during data migrations or catalog freezes.

Group-cache flush

Clear the in-process Entra group cache (1-hour TTL per user) to pick up new group assignments immediately for all active users.

§ 3 — Getting started

Getting started

The Data Dictionary uses your organisation's Entra ID (Microsoft Azure AD) account. No separate username or password is required.

Sign in

  1. Open the Data Dictionary URL in your browser.
  2. Click Sign in with Entra ID.
  3. Complete the Microsoft authentication flow (your browser may already have a session and skip this step).
  4. You are redirected to the search page. The catalog is ready to use.
No tables visible? If you see "You don't have access to any tables yet", your account has not been added to a data-access group. Contact your data platform administrator and ask them to add you to the appropriate group in Entra ID.

Navigate the application

The navigation bar at the top of every page has six sections:

Search

Full-text search and table detail view. This is the main page for most users.

Catalog

Hierarchical browser — drill from catalog → schema → table.

Discovery

Personalised feed — Recommended, Notable, Bookmarks, Recently Viewed.

Health

Documentation coverage metrics across the catalog.

Glossary

Business term definitions with links to related tables.

Admin

Admin-only dashboard (only visible to members of ADMIN_GROUPS).

§ 4 — How to

Search the catalog

  1. Click the Search tab in the navigation bar.
  2. Type a table name, column name, or business term in the search box. Results appear as you type.
  3. Results are sorted by relevance: exact name matches rank first, then prefix matches, then partial matches. Glossary terms appear below table results.
  4. Click View details → on any result to open the full table detail page.
Tip. Use the Catalog browser for browsing by schema, or Discovery for exploring tables your colleagues are actively working with.

Read a table detail page

The detail panel opens on the right side of the Search page when you select a result. It contains:

  1. Header: full Unity Catalog identifier (catalog.schema.table), table type (TABLE / VIEW), and freshness timestamp.
  2. Description & steward: the table description and the email address of the person responsible for this table.
  3. Columns: every column with its data type, Unity Catalog comment, business name override, and definition. Power users see an edit icon next to each field.
  4. Grants: the list of Entra principals (users and groups) with access to this table and their privilege level.
  5. Lineage: upstream tables that feed this table and downstream tables that consume it, up to two hops in each direction.
  6. Downstream impact: a count of dependent assets in the blast radius. A warning appears if any certified or production table is downstream.
  7. Data quality: the latest DQ grade (A–F) when Lakehouse Monitoring data is available.
  8. Data sample: top 100 rows from the table, visible only if you have SELECT on it.
  9. Export: the Export schema button downloads a CSV with column names, types, comments, and business names.

Bookmark and track tables

  1. Open the table detail page for any table.
  2. Click the Bookmark button (star icon) near the table header.
  3. The table is saved to your personal bookmarks list, accessible from Discovery → My Bookmarks.
  4. To remove a bookmark, click the Bookmarked button on the same table — it toggles off.
Recently Viewed is updated automatically every time you open a detail page. No action required — just browse and your history builds itself.

Leave a comment or question

  1. Open the table detail page for the table you want to comment on.
  2. Scroll to the Comments section at the bottom of the detail panel.
  3. Type your comment in the text area (max 1,000 characters) and click Send.
  4. To reply to an existing comment, click Reply beneath it.
Notification. The table steward receives an email notification for new comments when SMTP is configured by your platform team. Email failures do not block the comment from being saved.

Propose a metadata change Power users

If you are a member of an editor group (EDITOR_GROUPS), you can update table and column metadata directly from the detail page.

Edit a table description or steward

  1. Open the table detail page.
  2. Click the pencil icon next to the Description or Steward field.
  3. Make your changes and click Save.
  4. The change is applied immediately and pushed to Unity Catalog in the background.

Propose a column business name or definition

  1. Open the table detail page and find the column you want to update.
  2. Click the pencil icon next to the Business name or Definition field.
  3. Enter the new value (business name max 255 chars, definition max 2,000 chars) and click Save.
  4. Your change is submitted as a proposal. It will appear in the admin review queue before being published to Unity Catalog.
Note. Column overrides require admin approval before they are visible to other users and synced to Databricks. Table-level changes (description, steward) are published immediately.

Approve or reject a metadata proposal Admin

  1. Open the Admin tab from the navigation bar.
  2. In the Operations tab, find the Pending reviews section.
  3. Each pending proposal shows the column identifier, the current value, the proposed value, and the name of the editor who submitted it.
  4. Click Approve to publish the change to Unity Catalog, or Reject to discard it.
  5. Both actions are recorded in the audit log with your email and a timestamp.
Tip. If there are no pending proposals, the section shows "No pending reviews." The section only appears when there is at least one item in the queue.

Trigger and monitor a pipeline Admin

  1. Open the Pipelines tab from the navigation bar (visible to members of PIPELINE_GROUPS and admins).
  2. Select a pipeline from the list. Each entry shows its name, backend type (Databricks / ADF / ADO), and last run status.
  3. Click Start to trigger a run. The status panel updates automatically every 3 seconds.
  4. Monitor progress via the live percentage and lifecycle state displayed in the status card.
  5. Click Stop to cancel a run in progress. The run is cancelled via the backend API and the row is cleared.
One active run per pipeline. You cannot start a new run while an existing run is in progress. Wait for the current run to reach a terminal state (succeeded, failed, or cancelled) first.

Define a new pipeline (admins only)

  1. Open the Admin tab → Operations → Pipelines section.
  2. Click New pipeline and fill in the name, backend, and backend-specific fields (job ID for Databricks; subscription, resource group, factory, pipeline for ADF; organisation, project, pipeline ID for ADO).
  3. Click Save. The pipeline appears in the Pipelines tab immediately.
§ 5 — FAQ

Frequently asked questions

Why can I not see any tables?

Your Entra ID account is not assigned to any data-access group. Contact your data platform administrator and ask to be added to the appropriate group. If you were just added, sign out and sign back in — the app refreshes your group memberships on each new sign-in.

I was recently added to a group but still see no change.

Sign out using the Sign out link in the navigation bar, then sign back in. The app caches your group memberships for up to one hour; signing out clears your personal cache immediately. If the problem persists after re-signing in, ask an admin to flush the group-permissions cache from the Admin dashboard.

A table I know I can access in Databricks does not appear in the search results.

The Data Dictionary only shows tables with an explicit SELECT or MODIFY grant for your group in Unity Catalog, or tables marked SELECT_ALL_USERS. Databricks-level access via workspace roles is not reflected here. Ask your data engineer to grant the appropriate Unity Catalog privilege to your group.

The table description I see seems outdated.

Catalog metadata syncs nightly from Unity Catalog. If you made a change in Databricks directly (outside the Data Dictionary), it will appear at the next sync. If you updated it via the Data Dictionary's inline editor, it should be visible immediately and pushed to Databricks within minutes.

I submitted a metadata change but it is not visible to others.

Column business name and definition changes submitted by non-admin editors require admin approval before they are published. Check with your admin — the proposal is waiting in the pending-reviews queue in the Admin dashboard.

What does the data quality grade mean?

Grades A–F are derived from Lakehouse Monitoring checks run against the table. A = 90–100 % pass rate, B = 75–89 %, C = 60–74 %, D = 45–59 %, F = below 45 %. If no monitoring data is available, no badge is shown. Contact your data quality team for details on specific checks.

I cannot see the Admin tab.

The Admin tab is only visible to members of the ADMIN_GROUPS environment variable. Ask your platform administrator if you need admin access.

I cannot edit table or column metadata.

Inline editing is available to members of EDITOR_GROUPS. It may also be temporarily disabled globally by an admin (e.g., during a catalog migration). Check with your admin if the edit icon is missing from fields you expect to be able to edit.
