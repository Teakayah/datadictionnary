API and MCP server reference

Overview

The Data Dictionary exposes a permission-filtered REST API and an MCP (Model Context Protocol) server alongside the Streamlit UI. Both run from the same Docker image as a separate process on port 8080.

Start the server:

uvicorn src.api.main:app --host 0.0.0.0 --port 8080

Interactive OpenAPI docs are available at http://localhost:8080/docs.

Authentication

All endpoints (REST and MCP) require a Microsoft Entra ID Bearer token.

Authorization: Bearer

Acquire a token with the correct audience (defaults to CLIENT_ID):

# Using Azure CLI
az account get-access-token --resource $CLIENT_ID --query accessToken -o tsv

Set API_AUDIENCE when the API has its own app registration separate from the Streamlit app.

Groups are extracted from the token. If your account belongs to more than 150 groups (Entra overage), groups are resolved via Microsoft Graph using the same token — no extra credentials required.

REST endpoints

Health

GET /health

Returns {"status": "ok"}. No auth required. Used by k8s liveness probes.

List tables

GET /api/v1/tables
Authorization: Bearer

Returns all tables the caller is authorized to access. Results are cached for 10 minutes per (user groups) combination.

Response — array of TableSummary:

FieldTypeDescription
full_namestringUnity Catalog three-part identifier
catalog_namestringCatalog
schema_namestringSchema
table_namestringTable
table_descriptionstring?Business description or system comment
table_typestring?TABLE, VIEW, etc.
dq_scorestring?Data quality grade (A–F)
updated_atstring?Last modified timestamp

Table detail

GET /api/v1/tables/{catalog}/{schema}/{table}
Authorization: Bearer

Returns column metadata for a single table. Returns 404 if the table does not exist or the caller is not authorized.

Response — TableDetail:

FieldTypeDescription
full_namestringUnity Catalog identifier
columnsColumnInfo[]Ordered list of columns
ColumnInfo:
FieldTypeDescription
column_namestringColumn name
data_typestringDatabricks SQL type
descriptionstring?Business definition or system comment

Search

GET /api/v1/search?q=
Authorization: Bearer

Hybrid keyword search across table names, descriptions, column names, and business name overrides. Returns up to 50 results, sorted by relevance score. Results cached for 5 minutes per (query, user groups) combination.

Query parameters:

ParamRequiredDescription
qyesFree-text search string (min 1 character)
Response — array of SearchResult:
FieldTypeDescription
full_namestringTable Unity Catalog identifier
namestringMatched entity name (table or column)
match_typestringTable, Column, or Glossary
descriptionstring?Matched description
dq_scorestring?Data quality grade

Lineage

GET /api/v1/lineage/{catalog}/{schema}/{table}?depth=1
Authorization: Bearer

Returns upstream and downstream lineage edges for a table. depth controls how many hops to traverse (1–5, default 1).

Response — array of LineageEdge:

FieldTypeDescription
table_full_namestringSource table
directionstringupstream or downstream
entity_full_namestringRelated table/entity
entity_typestringTABLE, VIEW, etc.
depthintegerHop count from the source table

MCP server

The MCP endpoint is at POST /mcp (Streamable HTTP transport). Connect from any MCP-compatible client by pointing it at:

http://:8080/mcp

Connecting from VS Code Copilot

Add to .vscode/settings.json (or workspace settings):

{
  "github.copilot.mcpServers": {
    "data-dictionary": {
      "url": "http://localhost:8080/mcp",
      "headers": {
        "Authorization": "Bearer ${env:DATA_DICT_TOKEN}"
      }
    }
  }
}

Set DATA_DICT_TOKEN in your shell environment before launching VS Code.

Connecting from Claude Desktop

Add to claude_desktop_config.json:

{
  "mcpServers": {
    "data-dictionary": {
      "command": "npx",
      "args": ["-y", "@modelcontextprotocol/client-http", "http://localhost:8080/mcp"],
      "env": {
        "MCP_BEARER_TOKEN": ""
      }
    }
  }
}

Environment variables

VariableDefaultDescription
REDIS_URL(unset)Redis connection URL. Omit to run without cache.
API_AUDIENCECLIENT_IDExpected JWT audience claim. Override when the API has its own app registration.
Existing Entra ID variables (TENANT_ID, CLIENT_ID) are also used by the API for JWKS discovery and audience validation.

Redis cache

Results are cached in Redis to reduce load on Databricks. The cache key is a SHA-256 hash of the query arguments and the caller's group set.

If REDIS_URL is unset or Redis is unreachable, the API continues to work without caching — every request hits the database directly.

To deploy Redis in Kubernetes, apply the bundled manifests:

kubectl apply -f k8s/deployment-redis.yaml -f k8s/service-redis.yaml -f k8s/pvc-redis.yaml

Then set REDIS_URL=redis://dd-redis:6379 in k8s/configmap.yaml.
